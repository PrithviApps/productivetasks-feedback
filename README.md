# Productive Tasks feedback

Public bug reports and feature requests for Productive Tasks on web/PWA, Android and iOS. Application source code remains private.

- [Report a bug](https://github.com/PrithviApps/productivetasks-feedback/issues/new?template=bug_report.yml)
- [Suggest a feature](https://github.com/PrithviApps/productivetasks-feedback/discussions/categories/ideas)
- [Browse known bugs](https://github.com/PrithviApps/productivetasks-feedback/issues)

A free GitHub account is needed to post, comment or react. Search existing reports first; add details or a thumbs-up instead of duplicates.

## Reporting guidelines

Report one problem per issue. Include platform, app version, reproduction steps, expected and actual behavior. Optional screenshots should have personal information removed.

**Everything posted here is public.** Never post passwords, tokens, private task content, account details or raw diagnostic logs. For private account help or security concerns, email support@productivetasks.com.

Feature requests belong in Discussions. Explain the problem and proposed improvement. Votes help us understand interest but do not promise delivery dates. Confirmed bugs are tracked in Issues. Maintainers use needs-triage, needs-info, confirmed, in-progress and released labels. Close issues after the relevant released behavior is verified.

Be respectful, avoid spam and keep discussions relevant to Productive Tasks.
